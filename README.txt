ALYA HONDA PREMIUM V4.1
=======================

Isi folder:
- index.html        halaman utama
- detail.html       detail setiap model
- data.js           data sales, harga, katalog dan legacy
- editor.html       editor sederhana
- assets/alya.png   foto sales
- assets/cars/*.svg ilustrasi mobil lokal

UPLOAD KE GITHUB PAGES
1. Buat repository PUBLIC, misalnya: alya-honda-sragen
2. Upload SEMUA ISI folder ini. Pastikan index.html berada di root repository.
3. Settings > Pages > Build and deployment > Source: Deploy from a branch.
4. Branch: main, folder: / (root), lalu Save.
5. Tunggu beberapa menit sampai status menjadi live.

PENTING HARGA
Harga Jateng yang diberi label OTR referensi Jawa Tengah berasal dari tabel harga resmi Honda yang mencantumkan kota-kota seperti Solo, Klaten, Kudus, Pati, Salatiga, Cilacap, Magelang, Purwokerto, Semarang, Jepara, Pekalongan dan Tegal. Sragen tidak dicantumkan dalam tabel tersebut, jadi harga OTR Sragen harus dikonfirmasi ke dealer.
Model seperti City sedan, STEP WGN, e:N1, Prelude dan Super-ONE diberi label harga resmi Honda/OTR Jakarta atau hubungi dealer bila harga Jateng tidak tersedia pada sumber regional yang dipakai.

GAMBAR
V4.1 menggunakan ilustrasi SVG lokal supaya gambar tidak bergantung pada hotlink/server eksternal dan tetap tampil saat di-host di GitHub Pages. Jika nanti ingin mengganti dengan foto unit resmi, cukup ganti file SVG di assets/cars dengan gambar JPG/PNG dan sesuaikan nama file di data.js.
